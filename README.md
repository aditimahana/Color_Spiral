# Color Spirals 🎨

A collection of Python Turtle graphics experiments based on projects from *Teach Your Kids to Code*. These programs generate colourful geometric spirals by experimenting with different polygon side counts, rotation angles, pen colours, and line widths.

## 🖥️ Programs

| File | Description |
|---|---|
| `ColorSpiral1.py` | Creates a six-sided colourful spiral with gradually increasing line width. |
| `ColorSpiral2.py` | Creates a five-sided colourful spiral with gradually increasing line width. |
| `ColorSpiral3.py` | Creates a four-sided colourful spiral with gradually increasing line width. |
| `ColorSpiral4.py` | Creates a three-sided colourful spiral with gradually increasing line width. |

## 🛠️ Concepts Used

- Python Turtle Graphics
- `for` loops and `range()`
- Variables and mathematical expressions
- Lists and list indexing
- Modulo operator (`%`)
- Polygon geometry and rotation
- Changing pen colours and line widths
- Background customisation

## 🚀 How to Run

Make sure Python is installed, then run any of the files:

```bash
python ColorSpiral1.py
```

Replace the filename to explore the other variations.

## 🎨 Experimentation

Each program uses a different number of sides to create a distinct spiral pattern. The colours alternate throughout the design, while the pen width gradually increases to create a layered visual effect.
